# 领域学习OS · Top-Down Domain Learning Web App

一个页面优美、交互性强的 **AI 网页应用**，把「自上而下领域学习系统（Top-Down Domain Learning OS）」方法论变成可对话的学习体验。

> 从领域难题出发，反向构建理解该问题所需的最小知识体系：**领域全景 → 知识层级树 → 自上而下逐层讲解 → 理解检测 → 解法拆解 → 知识卡片**。

## 功能特性

- **苏格拉底式对话导师**：以对话方式引导学习，每个概念讲解后自动提出理解检测问题（解释题 / 因果题 / 判断题 / 反例题）
- **学习旅程可视化**：顶部与侧栏实时显示 6 个学习阶段进度（领域全景 / 知识树 / 讲解 / 检测 / 解法 / 卡片）
- **理解状态区**：已理解 / 基本理解 / 尚未理解 三区实时维护，点击概念可再次下钻讲解
- **知识层级树**：抽屉式交互树，点击节点直接下钻
- **8 个学习控制指令**：`@全景` `@下钻` `@退回` `@测试` `@应用` `@回到问题` `@现状` `@知识卡片` 一键发送
- **演示模式**：内置 4 个领域难题的完整教学内容（大模型幻觉 / 光学像差 / 位置编码 / 湍流），无需任何 API Key 即可体验
- **API 模式**：接入任意 OpenAI 兼容接口（DeepSeek / OpenAI / Moonshot / 智谱…），支持流式输出；Key 仅保存在浏览器本地
- **知识卡片**：一键生成 / 复制 / 下载纯 Markdown 知识卡片（公式纯文本，不依赖 LaTeX）

## 快速开始

1. 打开 `index.html`（或部署到 GitHub Pages / 任意静态托管）
2. 点击一个示例难题，或在输入框输入自己的领域难题
3. 按 Enter 发送，跟着导师的节奏回答检测问题
4. 需要真实 AI 讲解时：点击右上角「设置」→「接入 API」，填入接口地址、Key、模型名

## 设计

- 主题：极光夜空下的知识山峰（深海军蓝 + 极光青 + 星云紫 + 山顶金）
- 字体：Noto Serif SC（标题）/ Noto Sans SC（正文），自托管镜像加载
- 纯原生 HTML/CSS/JS 单文件实现，无构建工具、无外部依赖
- 响应式适配桌面 / 移动端，支持键盘操作与 reduced-motion

## 部署到 GitHub Pages

推送本仓库后，在仓库 Settings → Pages 中选择 `main` 分支根目录即可上线，访问地址为 `https://<用户名>.github.io/<仓库名>/`。
